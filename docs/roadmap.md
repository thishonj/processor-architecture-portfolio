# Roadmap (about 6 months, part-time)

| Weeks | Focus | Output |
|-------|-------|--------|
| 1–3  | C pointers, memory, debugging | Project 01 + exercises solved |
| 3–6  | RV32I, Ripes, Compiler Explorer | Project 02 complete with screenshots + `analysis.md` |
| 5–9  | Digital logic (HDLBits, Nand2Tetris 1–3) | Project 03 |
| 8–12 | Pipelining, hazards | Project 04 (Ripes data + stall counter) |
| 10–16 | SystemVerilog CPU | Project 05 v0.1 (done) → v0.2 with more instructions → v0.3 pipelined |
| 14–20 | Verification | Project 06: assertions, random tests, coverage |
| 18–24 | STM32 benchmarking | Project 07 |

Rules: commit weekly; every project has a README with *Status*, *How to reproduce*, *Results*, *Limitations*.
Study the RISC-V unprivileged spec (free PDF at riscv.org), *Digital Design and Computer Architecture: RISC-V Edition* (Harris & Harris) and Patterson & Hennessy *RISC-V Edition* alongside the projects.
