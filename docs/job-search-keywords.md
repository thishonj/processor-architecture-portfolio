# Job-search keywords (Germany)

**Roles (German / English):** Werkstudent, Praktikum, Abschlussarbeit / Masterarbeit, Working Student, Internship, Master Thesis, HiWi.

**Titles:** RTL Design Engineer, Digital Design Engineer, ASIC/FPGA Design Engineer, CPU/Processor Architect, Microarchitecture, Design Verification (DV) Engineer, Verification Engineer, Pre-silicon Validation, Embedded Software Engineer, Firmware Engineer, Performance Engineer.

**Skills:** SystemVerilog, Verilog, RTL, UVM, constrained-random, functional coverage, SystemVerilog Assertions (SVA), cocotb, Verilator, formal verification, RISC-V, ARM Cortex-M, pipelining, caches, memory hierarchy, AXI/AHB/APB, CDC, synthesis, timing closure, STA, FPGA (Vivado/Quartus), Python/Tcl scripting, Git, Linux, CI.

**Search sites:** LinkedIn, StepStone, Indeed, Xing, company career pages (Infineon, Bosch, NXP, Intel, AMD, Siemens EDA, Cadence, Synopsys, Arm, Fraunhofer institutes such as IIS/EAS). Also check FAU chairs for HiWi/thesis topics, e.g. computer architecture and hardware groups, and ask your supervisors directly.

**Tip:** Mirror words from the job ad only for skills you can demonstrate. If you used UVM only in a tutorial, say "UVM basics (tutorial-level)".

Company names are search starting points, not a statement that they are hiring or that they offer such positions.
